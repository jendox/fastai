## Начало работы

### Клонирование репозитория

Чтобы получить копию проекта на ваш локальный компьютер, выполните следующие шаги:

1.  **Откройте терминал** (Command Prompt, PowerShell, Git Bash или терминал в вашей IDE).
2.  **Перейдите в папку**, куда вы хотите склонировать проект, например:
    ```bash
    cd ~/my-projects
    ```
3.  **Выполните команду `git clone`**, указав URL репозитория:
    ```bash
    git clone https://github.com/jendox/fastai.git
    ```
4.  **Перейдите в склонированную директорию**:
    ```bash
    cd fastai
    ```

### Настройка виртуального окружения и установка зависимостей

Проект использует `uv` - быстрый менеджер пакетов Python.

1.  **Установите uv (если еще не установлен):**
    ```bash
    curl -LsSf https://astral.sh/uv/install.sh | sh # Linux/macOS
    ```
    ```bash
    powershell -c "irm https://astral.sh/uv/install.ps1 | iex" # Windows
    ```
2.  **Создайте виртуальное окружение и установите зависимости:**
    ```bash
    uv sync
    ```
3.  **Активируйте виртуальное окружение:**
    ```bash
    source .venv/bin/activate # Linux/macOS
    ```
    ```bash
    .venv\Scripts\activate # Windows
    ```

## Настройка переменных окружения

Перед первым запуском проекта необходимо настроить конфигурацию, используя файл `.env`.

### Быстрый старт

1.  **Скопируйте шаблон** конфигурации в новый файл:
    ```bash
    cp example.env .env
    ```
2.  **Отредактируйте** созданный файл `.env` в текстовом редакторе, заменив значения `your-...-...-key` на ваши реальные API-ключи.
3.  **Запустите** приложение.

> **⚠️ ВАЖНО: Безопасность репозитория**
> Файл `.env` содержит ваши личные API-ключи. **Никогда не коммитьте его в Git!**
> Убедитесь, что файл `.env` добавлен в `.gitignore`. Это предотвратит случайную утечку ваших секретных данных.

### Описание переменных в `.env`

| Переменная | Значение по умолчанию | Описание |
| :--- | :--- | :--- |
| `DEBUG` | `true` | Включает подробный вывод ошибок и логов для разработки. Для продакшена установите в `false`. |
| `DEEPSEEK__API_KEY` | `your-deepseek-api-key` | Ваш секретный API-ключ для доступа к DeepSeek API. |
| `DEEPSEEK__MAX_CONNECTIONS` | `5` | Максимальное количество одновременных подключений к API DeepSeek. |
| `DEEPSEEK__TIMEOUT` | `5` | Таймаут (в секундах) для запросов к DeepSeek API. |
| `UNSPLASH__API_KEY` | `your-unsplash-access-key` | Ваш Access Key для доступа к Unsplash API. |
| `UNSPLASH__MAX_CONNECTIONS` | `5` | Максимальное количество одновременных подключений к API Unsplash. |
| `UNSPLASH__TIMEOUT` | `20` | Таймаут (в секундах) для запросов к Unsplash API. |

### Как получить значения для переменных

#### Токен DeepSeek API

DeepSeek необходим для генерации HTML-кода по запросу пользователя.

**Официальный API (требует оплаты):**
Для работы с официальным API потребуется оплатить доступ. Обычно достаточно $1 для всех тестов в рамках обучения.

*Если у вас нет возможности оплатить официальный DeepSeek (например, с карт РФ), воспользуйтесь альтернативными решениями:*

**Альтернативные провайдеры (рекомендуется):**
Следующие сервисы предоставляют доступ к нейросетям, включая DeepSeek, с оплатой из РФ. Цена составляет около 10 руб. за одну генерацию сайта.

- **BotHub**: [https://bothub.studio](https://bothub.chat/deepseek-chat-v3-0324/api)
- **VseGPT**: [https://vsegpt.ru](https://vsegpt.ru/Docs/Models#h46-6)

**Инструкция:**
1.  Зарегистрируйтесь на выбранной платформе.
2.  Пополните баланс.
3.  В разделе с API-ключами скопируйте ваш токен.
4.  Вставьте его в переменную `DEEPSEEK__API_KEY` в файле `.env`.

#### Токен Unsplash API

Unsplash предоставляет бесплатное API для поиска и использования изображений. Подобранные изображения автоматически добавляются на сгенерированный сайт.

**Инструкция:**
1.  Зарегистрируйтесь как разработчик на [Unsplash](https://unsplash.com/documentation#creating-a-developer-account).
2.  Перейдите в [раздел Applications](https://unsplash.com/oauth/applications).
3.  Нажмите "New Application".
4.  Заполните форму: укажите название приложения, описание и согласитесь с условиями использования.
5.  После создания приложения, найдите в его настройках секцию "Keys".
6.  Скопируйте значение "Access Key".
7.  Вставьте его в переменную `UNSPLASH__API_KEY` в файле `.env`.

[Где найти Access Key в панели Unsplash](https://disk.yandex.ru/i/mQjaKs-7OfviqA)
